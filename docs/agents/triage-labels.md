# Triage Labels

工程技能使用五种 canonical triage role。本仓库的 GitHub label 使用完全相同的字符串。

| Canonical role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待 maintainer 评估 issue |
| `needs-info` | `needs-info` | 等待 reporter 补充信息 |
| `ready-for-agent` | `ready-for-agent` | spec 完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提及 canonical triage role 时，使用本表对应的 GitHub label。
